# API Overview

- include/constants.h: global constants
- include/error_codes.h: error codes enum
- include/game_structs.h: GameState, PlayerRecord
- include/utils.h: utilities
- project/filesystem/*: file and directory ops
- project/traps/*: traps, virus, hack utilities
- project/ui/*: simple console UI and command parser
- project/storage/*: storage, ranking, save/load, game state helpers
